# ESP32-S3 学习笔记与例程

> 一块 **ESP32-S3-WROOM-1-N16R8** 开发板（44 脚、双 USB-C）从零开始的完整学习记录：
> 芯片手册解读、引脚速查、Arduino 环境配置，以及按课号整理的一系列入门例程。
>
> 所有结论都对应商家提供的三份原始资料：`ESP32S3原理图.pdf`、`ESP32数据手册.pdf`、`引脚图.jpg` / `尺寸图.png`。

---

## 这是什么

这个仓库不是某个"库"，而是**一块具体开发板的学习资料包**：

- **给初学者的电路与引脚说明**：这块板 44 个脚分别是什么、哪些能用、哪些是坑；
- **可直接编译上传的 Arduino 例程**：从"打印板子信息"到"按键控灯""读芯片温度""驱动舵机"；
- **一份持续更新的学习路线**：每学会一个外设就加一个例程。

代码全部在 **ESP32 Arduino 核心 3.3.10** 下编译验证通过，不依赖任何第三方库。

## 硬件

| 项目 | 参数 |
|---|---|
| 核心模组 | ESP32-S3-WROOM-1-N16R8 |
| 芯片 | ESP32-S3，Xtensa LX7 **双核**，最高 240 MHz |
| Flash | **16 MB** |
| PSRAM | **8 MB（Octal / 八线）** ← 决定了 GPIO35/36/37 不可用 |
| 无线 | Wi-Fi 2.4 GHz + 蓝牙 5 (LE) |
| 逻辑电平 | **3.3 V** |

| 接口 | 两个 USB-C：`USB`（芯片原生，GPIO19/20）、`COM`（CH340C 串口，GPIO43/44） |
| 尺寸 | 板体 57.15 × 25.4 mm，含排针宽 27.94 mm，总长 63.61 mm |

## 快速开始

1. 安装 **Arduino IDE 2.x**，在"开发板管理器"里安装 **esp32 by Espressif**（本项目用 3.3.10 验证）；
2. 打开 `sketch/` 下任意一个 `.ino`；
3. 在"工具"菜单里按下表设置：

   | 菜单项 | 选择 |
   |---|---|
   | Board | **ESP32S3 Dev Module** |
   | Flash Size | **16MB (128Mb)** |
   | PSRAM | **OPI PSRAM** |
   | Partition Scheme | **16M Flash (3MB APP/9.9MB FATFS)** |
   | USB CDC On Boot | Disabled（用 `COM` 口时） |

4. 选好端口（插 `COM` 口后出现的 COMx），点上传；
5. 打开**串口监视器**，波特率 **115200** 查看输出。

### `sketch/L01_hello_board/L01_hello_board.ino`

**第 1 课：确认板子是不是"真的 N16R8"。**

- 串口打印：芯片型号、版本、核心数、主频、Flash 大小、PSRAM 大小、MAC、复位原因；
- 板载 WS2812B 彩灯（GPIO48）循环显示 红 → 绿 → 蓝 → 灭。

**用途**：新板到手第一件事就烧它。看到 `Flash : 16 MB` 和 `PSRAM : 8 MB` 就说明开发板选项全对；`PSRAM : 0 MB` 说明菜单里没选 `OPI PSRAM`。

**关键 API**：`ESP.getPsramSize()`、`ESP.getFlashChipSize()`、`ESP.getEfuseMac()`、`rgbLedWrite(48, r, g, b)`。

---

### `sketch/L03_button_led/L03_button_led.ino`

**第 3 课：数字输入 + 数字输出。**

- 按键接 GPIO4（另一端接 GND），用芯片**内部上拉**，不接外接电阻；
- LED 接 GPIO5（串 220Ω~1kΩ 电阻到 GND）；
- 按一下翻转一次状态，串口同步打印"开/关"。

**教学点**：`INPUT_PULLUP` 的用法、机械按键**消抖**、边沿判断、用 `millis()` 代替 `delay()` 不阻塞。

---

### `sketch/L04_button_led_sync/L04_button_led_sync.ino`

**第 4 课：一次动作控制两个灯。**

在 L03 基础上加了一行：把"开/关"封装成 `setLamp(bool)`，同时驱动**外接 LED（GPIO5）**和**板载彩灯（GPIO48）**。

**教学点**：

- 这块板的核心把 `LED_BUILTIN` 定义成板载彩灯，所以 `digitalWrite(LED_BUILTIN, HIGH)` 就能点亮它（白色，亮度 64）；
- 想换颜色时改用 `rgbLedWrite(48, r, g, b)`；
- 把"状态变化"集中到一个函数里，以后加灯只改一处。

---

### `sketch/L05_chip_temp/L05_chip_temp.ino`

**第 5 课：读取 ESP32-S3 的片内温度传感器。**

- 每 1000 ms 调用一次 `temperatureRead()`，打印当前温度、本次上电以来的最低/最高；
- 不需要任何外接元件。

**注意**：测的是**芯片自身的温度**（结温），不是室温，通常比环境温度高几度；核心把这个传感器按 10~50 ℃ 量程配置，超出范围的读数只能当参考。

**教学点**：`temperatureRead()`、`isnan()` 判空、非阻塞定时（`millis()` 差值）。

---

### `sketch/L06_servo_sweep/L06_servo_sweep.ino`

**第 6 课：用硬件 PWM 驱动 SG90 舵机。**

- 信号线接 GPIO6，用核心自带的 LEDC 产生 **50 Hz** PWM，**不需要安装任何舵机库**；
- 上电先回中位 90°，然后 0° → 180° → 0° 来回扫动；
- 角度到脉宽的换算是标准舵机协议（0.5~2.4 ms 对应 0~180°）。

**教学点**：`ledcAttach(pin, 50, 14)` + `ledcWrite()`、舵机的 PWM 协议、`map()` 换算。

**供电提醒（很重要）**：SG90 必须用 **5 V 独立电源**，`GND` 与开发板共地。
不要接 3.3 V（转不动），也不要指望开发板的 5V 排针（这块板的 5V 脚是输入向的）。
只插 USB、没有外部电源时，可以先接 3.3 V 让舵机"慢慢转"，但**不能带负载、不能堵转**。

## 引脚使用约定（全仓库通用）

| 类别 | 引脚 | 能不能用 |
|---|---|---|
| ✅ 推荐自由使用 | GPIO1、2、4~18、21、38~42、47 | 可以（39~42 是 JTAG 脚，不用调试时可当普通 IO） |
| ❌ PSRAM 占用 | **GPIO35 / 36 / 37** | 绝对不要用 |
| ⚠️ 原生 USB | GPIO19 / 20 | 用了 USB 口就废 |
| ⚠️ 串口（CH340） | GPIO43 / 44 | 用了串口监视器就乱码 |
| ⚠️ Strapping | GPIO0 / 3 / 45 / 46 | 可用，但上电瞬间别给固定电平 |
| 🎨 板载彩灯 | GPIO48 | 数据线串了跳线 J3 |
