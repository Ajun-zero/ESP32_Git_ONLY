# ESP32-S3 学习例程（ESP32-S3-WROOM-1-N16R8）

> 一块 **ESP32-S3-WROOM-1-N16R8** 开发板（44 脚、双 USB-C）的入门例程合集。
> 每个文件夹就是一个独立的 Arduino sketch，按学习顺序编号，
> 全部在 **ESP32 Arduino 核心 3.3.10** 下编译验证通过，**不依赖任何第三方库**。

---

## 一、这个仓库是什么

**它不是库（library），不需要"安装"**，而是一组可以直接打开、编译、上传的 Arduino 例程：

- 每个 `L0x_xxx/` 文件夹 = 一个完整的 sketch（文件夹名和 `.ino` 文件名相同，这是 Arduino 的硬性要求）；
- 想用哪个，就在 Arduino IDE 里打开对应文件夹里的 `.ino`，选好开发板、端口和菜单参数，点上传；
- 例程按难度递增，后面的会复用前面的知识（例如 L04 是 L03 的升级版，L07 用到 L03 的 LED 接法）。

配合一块具体的板子写成：**ESP32-S3-WROOM-1-N16R8**（16 MB Flash + 8 MB 八线 PSRAM）。
换别的 ESP32-S3 板子大部分代码也能用，但**引脚编号和"禁区"要以你自己的板子为准**。

## 二、硬件参数

| 项目 | 参数 |
|---|---|
| 核心模组 | ESP32-S3-WROOM-1-N16R8 |
| 芯片 | ESP32-S3，Xtensa LX7 **双核**，最高 240 MHz |
| Flash | **16 MB** |
| PSRAM | **8 MB（Octal / 八线）** ← 这决定了 GPIO35/36/37 不可用 |
| 无线 | Wi-Fi 2.4 GHz + 蓝牙 5 (LE) |
| 逻辑电平 | **3.3 V**（不是 5 V） |
| 板载外设 | WS2812B 彩灯（GPIO48）、RST 按键、BOOT 按键、电源灯、TX/RX 指示灯 |
| USB 口 | 两个 Type-C：`USB`（芯片原生，GPIO19/20）、`COM`（CH340C 串口，GPIO43/44） |
| 尺寸 | 板体 57.15 × 25.4 mm，含排针宽 27.94 mm，总长 63.61 mm |

## 四、每个例程在做什么

### L01 · `L01_hello_board` —— 确认板子身份

| 项目 | 内容 |
|---|---|
| 作用 | 串口打印芯片信息（型号、版本、核心数、主频、Flash、PSRAM、MAC、复位原因），并让板载彩灯循环变色 |
| 接线 | 无需接线 |
| 引脚 | GPIO48（板载 WS2812B） |
| 现象 | 串口出现 `Flash : 16 MB` / `PSRAM : 8 MB`；彩灯 红→绿→蓝→灭 循环 |
| 关键 API | `ESP.getPsramSize()`、`ESP.getFlashChipSize()`、`ESP.getEfuseMac()`、`rgbLedWrite(48, r, g, b)` |

**新板到手第一件事就烧它。** 如果显示 `PSRAM : 0 MB`，说明开发板菜单里没选 `OPI PSRAM`。

---

### L02 · `L02_uart_login` —— 串口收发：发 1 回"登录成功"

| 项目 | 内容 |
|---|---|
| 作用 | 从串口接收一条指令，等于 `1` 时回复"登录成功"，其它内容提示未知指令 |
| 接线 | 无需接线（用 USB 线的 `COM` 口） |
| 引脚 | 无（走 UART0 / USB 串口） |
| 现象 | 发送 `1` + 回车 → 串口返回 `收到：1` 和 `登录成功` |
| 关键 API | `Serial.available()`、`Serial.readStringUntil('\n')`、`String::trim()` |

**教学点**：串口不是"一次给一整句"，而是一个字节一个字节来的，所以要**读到换行为止**才算一条指令；
串口监视器右下角的"行结尾"必须选 **新建行 / 回车**，选"无"就永远收不到完整指令。

---

### L03 · `L03_button_led` —— 按一下开，再按一下关

| 项目 | 内容 |
|---|---|
| 作用 | 按键翻转 LED 状态，串口同步打印"开/关" |
| 接线 | 按键：一端 GPIO4，另一端 GND；LED：GPIO5 → 220Ω~1kΩ → 长脚，短脚 → GND |
| 引脚 | 输入 GPIO4（内部上拉）、输出 GPIO5 |
| 现象 | 每按一次，灯亮/灭切换一次 |
| 关键 API | `pinMode(pin, INPUT_PULLUP)`、`digitalRead()`、`millis()` |

**教学点**：内部上拉（省掉外接电阻）、机械按键**消抖**、只响应"按下"这个边沿、用 `millis()` 代替 `delay()` 不阻塞。

---

### L04 · `L04_button_led_sync` —— 外接灯和板载灯一起亮

| 项目 | 内容 |
|---|---|
| 作用 | 在 L03 基础上增加板载彩灯，按一下两盏灯同时亮/灭 |
| 接线 | 与 L03 完全相同（不需要额外接线） |
| 引脚 | GPIO4（按键）、GPIO5（外接 LED）、GPIO48（板载彩灯） |
| 现象 | 外接 LED 与板载彩灯同步开关 |
| 关键 API | `digitalWrite(LED_BUILTIN, ...)`、`rgbLedWrite(48, r, g, b)` |

**教学点**：这块板的核心把 `LED_BUILTIN` 定义成板载彩灯，所以 `digitalWrite(LED_BUILTIN, HIGH)` 就能点亮它（白色，亮度 64）；
把"开关灯"封装成 `setLamp(bool)`，以后加灯只改一处。

---

### L05 · `L05_chip_temp` —— 读芯片内部温度

| 项目 | 内容 |
|---|---|
| 作用 | 每秒读一次片内温度传感器，打印当前温度 + 本次上电以来的最低/最高 |
| 接线 | 无需接线 |
| 引脚 | 无 |
| 现象 | 串口每秒输出一行，例如 `温度：30.30 ℃  最低：28.30  最高：30.30` |
| 关键 API | `temperatureRead()`、`isnan()`、`millis()` 非阻塞定时 |

**注意**：测的是**芯片自身温度（结温）**，不是室温，通常比环境高几度；核心把该传感器按 10~50 ℃ 量程配置，超出范围只能当参考。

---

### L06 · `L06_servo_sweep` —— 舵机 0°~180° 扫动

| 项目 | 内容 |
|---|---|
| 作用 | 用硬件 PWM 驱动 SG90（180° 舵机），上电回中位后来回扫动 |
| 接线 | 舵机 棕→GND、红→外部 5V、黄（或橙）→GPIO6 |
| 引脚 | 输出 GPIO6（50 Hz PWM） |
| 现象 | 上电先转到 90°，然后 0°→180°→0° 循环 |
| 关键 API | `ledcAttach(pin, 50, 14)`、`ledcWrite()`、`map()` |

**教学点**：舵机控制协议（50 Hz、脉宽 0.5~2.4 ms 对应 0~180°）、用核心自带的 LEDC 做硬件 PWM（**不用装舵机库**）。

**供电提醒（最容易踩的坑）**：

- SG90 标称 **4.8~6 V**，堵转电流可达 **700 mA**，必须用**独立 5 V 电源**；
- 舵机的 GND 必须和开发板的 GND 连在一起（共地）；
- 接 3.3 V 只能"慢慢转"，且不能带负载、不能堵转；
- 这块板的 5V 排针是**输入向**的（经二极管接 VBUS），不要指望它给舵机供电。

---

### L07 · `L07_breathing_led` —— 正弦呼吸灯

| 项目 | 内容 |
|---|---|
| 作用 | 外接 LED 与板载彩灯同步做"呼吸"渐亮渐暗，4 秒一个周期 |
| 接线 | 与 L03 的 LED 相同：GPIO5 → 330Ω → LED 长脚，短脚 → GND |
| 引脚 | GPIO5（5000 Hz PWM）、GPIO48（板载彩灯） |
| 现象 | 外接白灯平滑呼吸，板载彩灯青蓝色同步呼吸 |
| 关键 API | `ledcAttach(pin, 5000, 12)`、`ledcWrite()`、`cosf()`、`powf()` |

**教学点**：

1. 用 `(1 - cos(2πt)) / 2` 生成两端斜率为 0 的平滑曲线，避免"到顶点硬拐弯"；
2. 再套 **gamma 2.2** 做亮度校正——人眼对亮度的感知是非线性的，不校正的话暗部变化会显得特别快；
3. PWM 频率 5 kHz 远高于人眼闪烁阈值，12 位分辨率有 4096 级亮度；
4. 全程不用 `delay()`，每 20 ms 更新一次。

## 五、快速开始

1. 安装 **Arduino IDE 2.x**，在"开发板管理器"里装 **esp32 by Espressif**（本项目用 3.3.10 验证）；
2. 打开任意一个 `L0x_xxx/L0x_xxx.ino`；
3. 在"工具"菜单里设置：

   | 菜单项 | 选择 |
   |---|---|
   | Board（开发板） | **ESP32S3 Dev Module** |
   | Flash Size | **16MB (128Mb)** |
   | PSRAM | **OPI PSRAM** |
   | Partition Scheme | **16M Flash (3MB APP/9.9MB FATFS)** |
   | USB CDC On Boot | Disabled（用 `COM` 口时） |

4. 选好端口（插板上标 `COM` 的口后出现的 `COMx`），点 **上传**；
5. 打开**串口监视器**（右上角图标或 `Ctrl+Shift+M`），波特率 **115200**。

> 上传报 `no upload port provided` = 端口没选；列表里找不到 COM 口 = 线是充电线，或没装 CH340 驱动。

## 六、引脚速查

### 6.1 两排引脚（板子 USB 口朝下、天线朝上，从上往下）

**左排（22 个）**

```
3V3  3V3  RST  4  5  6  7  15  16  17  18  8  3  46  9  10  11  12  13  14  5V  GND
```

**右排（22 个）**

```
GND  TX(43)  RX(44)  1  2  42  41  40  39  38  37  36  35  0  45  48  47  21  20  19  GND  GND
```

> 板子上印的数字是 **GPIO 编号**，不是"第几脚"。

### 6.2 禁区（全仓库通用）

| 引脚 | 原因 | 结论 |
|---|---|---|
| **GPIO35 / 36 / 37** | 被 8 MB 八线 PSRAM 占用 | **绝对不要用**，一用就死机/重启 |
| GPIO19 / 20 | 芯片原生 USB（D− / D+） | 当普通 IO 用，USB 口就废 |
| GPIO43 / 44 | UART0，接 CH340C 串口 | 用了串口监视器会乱码 |
| GPIO0 / 3 / 45 / 46 | strapping 脚 | 可用，但**上电瞬间**别给固定电平 |
| GPIO48 | 板载彩灯数据线 | 想当普通 IO 要先断开跳线 J3 |

**推荐自由使用的引脚**：GPIO1、2、4~18、21、38~42、47。

## 七、常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 上传报 `no upload port provided` | 端口没选 | 工具栏"端口"下拉里选 COMx |
| 端口列表里没有新 COM 口 | 充电线 / 缺 CH340 驱动 | 换数据线；装 WCH CH340 驱动 |
| 卡在 `Connecting.....` | 进不了下载模式 | 按住 BOOT → 点一下 RST → 松开 BOOT，再上传 |
| 串口乱码 | 波特率不对 | 改成 115200 |
| L01 显示 `PSRAM : 0 MB` | 菜单 PSRAM 没选对 | 改 `OPI PSRAM` 重新编译 |
| L02 发 1 没反应 | 串口监视器"行结尾"选了"无" | 改成"新建行"或"回车" |
| 板子莫名重启 | 用了 GPIO35/36/37，或供电不足（如舵机） | 换引脚 / 给舵机独立供电 |
| 舵机很慢、没力 | 用 3.3 V 供电 | 换 5 V 独立电源，并共地 |
